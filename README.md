# 小白护栏

给不会写代码、用 Claude Code 做东西的人准备的护栏包。

装上以后，Claude Code 会：

- 推送代码、发布、上线之前，先问你；
- 大范围删除文件或清空数据之前，先问你；
- 不会为一件小事开出一堆子代理（会额外消耗额度的“分身”）；
- 同一条命令原地打转时停下来，告诉你卡在哪里；
- 报错时用大白话说明发生了什么、要不要紧、你该做什么；
- 说话用大白话，说“做好了”之前先自己验证。

[English](README.en.md)

## 适合谁

- 看不懂代码，主要靠 Claude Code 帮你做网站、小工具或自动化的人；
- 被 AI 擅自推送、删错文件、反复重试烧光额度坑过的人；
- 通过第三方接口使用 Claude Code、经常看到看不懂的报错的人。

## 安装

需要先装好 Claude Code，并且电脑上有 Node.js 18 或更新的版本。

1. 下载本仓库：点页面上的 Code → Download ZIP，然后解压。
2. 在解压后的文件夹里打开终端，运行：

```
node install.mjs
```

3. 关掉 Claude Code 再重新打开。

安装程序会先备份 `settings.json` 和 `CLAUDE.md`，备份文件的位置会打印在屏幕上。重复运行不会重复添加。

## 卸载

在同一个文件夹里运行：

```
node uninstall.mjs
```

卸载只移除本工具装进去的内容，你原有的设置和规矩保持不变。

## 里面有什么

| 部分 | 作用 |
| --- | --- |
| 白话规矩（`rules/CLAUDE.md`） | 要求 Claude 用大白话说话、主动说明花钱和删除、验证后才说做好了、失败两次就停下来问你。 |
| 发布护栏 | 拦下 `git push`、`npm publish`、`vercel --prod`、`railway up` 等命令，直到你明确说“推”或“发布”。 |
| 删除护栏 | 拦下 `rm -rf`、`Remove-Item -Recurse`、`git reset --hard`、`DROP TABLE` 等命令，直到你明确说“删”。删除 `node_modules`、`dist` 这类可以重新生成的文件夹不拦。 |
| 子代理护栏 | 每个对话里，你没提到子代理时最多开 2 个，再多就要先问你。 |
| 打转护栏 | 同一条命令在中间没有任何修改的情况下连续执行到第 3 次时叫停，让 Claude 跟你说明卡在哪里。 |
| 报错急救（`skills/error-doctor`） | 遇到 529、429、401、额度用完、超时、内容太长等报错时，用大白话解释并给出下一步。 |

## 护栏怎么判断你同意了

护栏会看你最近说的一句话里有没有表示同意的词，例如“推”“发布”“上线”“删”“清空”“push”“deploy”。

“先别推”“不要删”“don't push”这类前面带否定词的说法不算同意。判断不准时，护栏宁可当作你没同意，让 Claude 再问你一次。

## 调整设置

在 Claude Code 的设置目录（通常是 `~/.claude`）里新建 `xiaobai-guard.json`，可以改两个数字：

```json
{
  "maxAgentsWithoutAsking": 2,
  "maxSameCommandInARow": 2
}
```

- `maxAgentsWithoutAsking`：没提到子代理时，每个对话最多允许开几个。
- `maxSameCommandInARow`：同一条命令最多允许连续执行几次。

## 已知限制

- 护栏只能拦下 Claude Code 在终端里执行的命令。在网页上点按钮、用其他工具发布或删除，拦不到。
- 判断同意靠关键词，不是百分之百准确。
- 只覆盖常见的发布和删除命令，完整列表见 `hooks/checks` 里的文件。
- 目前只支持 Claude Code。
